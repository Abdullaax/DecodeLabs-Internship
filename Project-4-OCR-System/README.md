# Project 4 — OCR System 🔎

## Overview

This was my fourth project during the DecodeLabs Artificial Intelligence Internship.

The project uses computer vision preprocessing and OCR to extract text from images and evaluate the confidence of the recognized text.

## Workflow

Input Image
↓
Grayscale
↓
Gaussian Blur
↓
Adaptive Thresholding
↓
Tesseract OCR
↓
Text Extraction
↓
Confidence Check
↓
PASS / LOW CONFIDENCE

## Features

- Multiple image processing
- Grayscale conversion
- Gaussian blur
- Adaptive thresholding
- OCR text extraction
- Confidence calculation
- 80% confidence validation
- Processed image generation

## Technologies Used

- Python
- OpenCV
- Pytesseract
- Tesseract OCR
