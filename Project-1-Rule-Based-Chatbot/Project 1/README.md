# Project 1 — Rule-Based AI Chatbot 🤖

## Overview

This was my first project during the DecodeLabs Artificial Intelligence Internship.

The project involved developing a simple rule-based chatbot using Python. The chatbot interacts with the user through predefined responses and commands.

The project was designed to understand the basic logic behind conversational systems before moving towards more advanced AI concepts.

## Features

- Interactive chatbot conversation
- Greeting detection
- Predefined responses
- User input handling
- Basic personalization
- Continuous conversation loop
- Exit command
- Console-based interface

## Technologies Used

- Python

## Concepts Learned

- Variables
- Strings
- Conditional statements
- If-else logic
- Loops
- Functions
- User input
- Basic program flow

## How It Works

The chatbot receives input from the user and checks it against predefined rules.

```text
User Input
    ↓
Process Input
    ↓
Check Predefined Rules
    ↓
Find Matching Response
    ↓
Display Response
    ↓
Continue Conversation
```
## What I Learned

This project helped me strengthen my Python fundamentals and understand how a simple conversational system can be created using rule-based logic.

I also learned how to structure a Python program into different functions and create an interactive command-line application.
