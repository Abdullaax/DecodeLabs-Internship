# Project 1 — Rule-Based AI Chatbot 🤖

A rule-based AI chatbot developed as part of my DecodeLabs Artificial Intelligence internship.

## Overview

The project focuses on building a simple interactive chatbot using Python and rule-based decision making.

The chatbot responds to user inputs according to predefined conditions and continues interacting until an exit command is entered.

## Features

- Greeting responses
- Rule-based conversation
- User input handling
- Continuous conversation loop
- Exit commands
- Basic personalization

## Technologies

- Python

## Concepts Learned

- Conditional statements
- Loops
- User input handling
- Rule-based decision making
- Basic chatbot development
