# DecodeLabs Internship 🤖

This repository contains the projects I developed during my Artificial Intelligence internship at DecodeLabs.

The projects allowed me to gradually apply different AI and programming concepts, starting from basic Python logic and progressing towards machine learning, recommendation systems, and computer vision.

## Projects

### Project 1 — Rule-Based AI Chatbot

A Python-based rule-driven chatbot that uses conditional logic, user input, greetings, and exit commands to create a simple interactive conversation.

**Technologies:** Python

---

### Project 2 — Data Classification

A supervised machine learning project focused on preparing data, splitting it into training and testing sets, training a classification model, and evaluating its predictions.

**Technologies:** Python, Pandas, NumPy, Scikit-learn

---

### Project 3 — AI Recommendation System

A simple recommendation system that matches user preferences with movie attributes and generates recommendations using basic similarity and matching logic.

**Technologies:** Python

---

### Project 4 — OCR System

A computer vision project that extracts text from images using OpenCV and Tesseract OCR. The system performs image preprocessing using grayscale conversion, Gaussian blur, and adaptive thresholding before extracting text and checking OCR confidence.

**Technologies:** Python, OpenCV, Pytesseract, Tesseract OCR
