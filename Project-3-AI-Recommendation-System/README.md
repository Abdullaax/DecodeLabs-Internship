# Project 3 — AI Recommendation System 🎬

## Overview

This was my third project during the DecodeLabs Artificial Intelligence Internship.

The project focuses on building a simple recommendation system that uses user preferences and movie attributes to generate relevant recommendations.

## How It Works

User Preferences
↓
Movie Attributes

↓
Similarity Logic

Recommended Movies

- Preference matching
- Recommendation generation
- Similarity-based logic
